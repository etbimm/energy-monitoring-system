Flowchart Program Energy Monitoring System

Disusun dari implementasi kode: acquisition worker (Python + pymodbus), backend FastAPI, MQTT Mosquitto, PostgreSQL/TimescaleDB, dan dashboard Next.js.

1. Flowchart Program Utama – Acquisition Worker

Loop utama pembacaan power meter: memuat meter dari database, terhubung ke MQTT, lalu melakukan polling setiap 5 detik dengan jadwal interval tetap.

File: 01-program-utama-akuisisi.svg

2. Subrutin Polling Gateway dan Power Meter

Dijalankan paralel untuk tiap gateway; meter dalam satu jalur RS485 dibaca berurutan, hasilnya dipublikasikan ke MQTT.

File: 02-subrutin-polling-meter.svg

3. Subrutin Baca Register Modbus dan Decode

Membaca blok register satu meter melalui gateway RS485-to-Ethernet (Modbus TCP) sesuai profil model, lalu decode dan normalisasi.

File: 03-subrutin-baca-modbus.svg

4. Flowchart Program Backend – Penerimaan Data MQTT

Backend FastAPI menjalankan task latar (MQTT subscriber dan offline watcher) sambil melayani REST API dan WebSocket.

File: 04-program-backend-mqtt.svg

5. Subrutin Ingest Telemetry

Memvalidasi meter, menghitung nilai turunan (PF, kVAh), menyimpan ke PostgreSQL/TimescaleDB, mengevaluasi alarm, lalu menyiarkan data ke dashboard.

File: 05-subrutin-ingest-telemetry.svg

6. Subrutin Evaluasi Alarm

Alarm dibuat bila kondisi abnormal bertahan ≥ 30 detik dan dinyatakan normal bila kondisi normal (di luar deadband) bertahan ≥ 30 detik.

File: 06-subrutin-evaluasi-alarm.svg

7. Subrutin Offline Watcher

Memeriksa umur data setiap meter setiap 15 detik: > 30 detik warning, > 180 detik critical dan dikirim notifikasi Telegram.

File: 07-subrutin-offline-watcher.svg

8. Flowchart Program Frontend – Dashboard

Dashboard Next.js memuat data lewat REST, lalu memperbarui tampilan secara realtime lewat WebSocket dengan sinkronisasi REST berkala setiap 60 detik.

File: 08-program-frontend-dashboard.svg
